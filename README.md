# PharmaSupport AI - 薬局加算・進捗管理ダッシュボード (Step 1)

現場の薬剤師の負担を軽減し、調剤報酬改定の施設基準達成および個別算定漏れを防止するためのWebダッシュボード＆ナビゲーションシステムです。

## 主な機能

1. **薬局全体: 施設基準ダッシュボード**
   - 地域支援体制加算（1〜4）、医薬品供給対応体制加算、連携強化加算の適合判定
   - 麻薬・在宅・かかりつけ・トレーシングレポート・後発品割合などの進捗メーター
   - 「あと○件で達成」の目標値逆算と優先アクションの提示
   - パラメータシミュレーター（スライダーや数値を動かしてリアルタイムに判定変化を確認）

2. **個別患者: 加算算定ナビゲーター**
   - 患者属性（年齢、手帳持参、かかりつけ同意、在宅療養など）と処方内容（麻薬、ハイリスク薬、抗がん剤、吸入薬など）をチェックするだけで、算定可能な個別加算を即座にサジェスト
   - 薬歴記載の必須ポイント（監査対策）とワンクリックコピー機能
   - 個別算定が薬局全体の施設基準（地域支援加算の実績）にどう貢献するか（+1カウント）を可視化

3. **朝礼・出勤時デイリーサマリーシート（印刷最適化）**
   - A4用紙1枚に収まる出勤時用の目標進捗レポート
   - ブラウザから直接印刷可能

## 起動方法

### 1. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. サーバー起動
```bash
python main.py
```
または `run_app.bat` をダブルクリックします。

ブラウザで `http://localhost:8000` にアクセスしてください。
